# Contributing

Thanks for considering a contribution! To keep licensing clean and allow future commercialization, we require assignment and a CLA check before merging.

1. **License**: The project is AGPL-3.0; commercial licenses are available (see `LICENSE-COMMERCIAL.md`).
2. **Sign the CLA**: Sign `CLA.md` via the CLA Assistant check on your first PR. We only accept contributions from signers.
3. **Upstream Requirement**: If you deploy or distribute a modified version, you agree to submit those modifications as a pull request within 30 days of first deployment/distribution (see `CLA.md`).
4. **How to contribute**:
   - Fork and branch from `main` (or the primary branch).
   - Keep changes focused; add tests where applicable.
   - Ensure lint/tests pass.
   - Open a PR; the CLA Assistant status must be green before review.
5. **Communication**: Use PR comments/issues for discussion; avoid embedding sensitive data.
